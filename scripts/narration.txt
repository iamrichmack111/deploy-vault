Welcome to DeployVault, a lightweight Kubernetes incident training system. The readiness dashboard tracks mastery across forty-six realistic scenarios. Smart practice targets weak areas automatically. In the incident lab, investigate simulated cluster output using real kubectl commands, then submit a root-cause analysis for rubric-based grading. Interview mode adds a timer and spoken-answer transcription. Study mode uses spaced repetition, while exam mode delivers ten randomized production incidents. DeployVault runs locally with Python, ships as a multi-architecture container, and installs as a desktop application on macOS, Linux, and Windows.
